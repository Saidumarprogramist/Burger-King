# Burger King — учебное приложение заказа еды

Неофициальный **frontend demo**, созданный для изучения React и для портфолио. Не связан с Burger King; товарные изображения и названия используются в учебных целях. Цены демонстрационные и могут отличаться от реальных.

## Возможности
- Категории, поиск, адаптивная навигация и карточки товаров.
- Добавление товаров, изменение количества, удаление и очистка корзины.
- Проверка состава и суммы; подтверждение **демонстрационного** заказа.
- Сохранение только ID и количества в localStorage с проверкой сохранённых данных.
- Клавиатурное управление модальными панелями; поддержка reduced motion и заглушки для отсутствующих изображений.

**Важно:** приложение не отправляет заказ в ресторан, не принимает оплату, не собирает персональные данные и не использует backend.

## Запуск
Требуется Node.js >=22.12.
```bash
npm ci
npm run dev
npm run lint
npm test
npm run build
npm run preview
```

## Архитектура
- `src/constants/menu.js` — каталог, оригинальные числовые ID внутри категории.
- `src/utils/cart.js` — стабильные глобальные ID `category-id`, чистые операции, проверка localStorage и расчёты.
- `src/components/cart/CartDrawer.jsx` — корзина, проверка и демо-подтверждение.
- `src/hooks/useDialog.js` — Escape, focus trap, восстановление фокуса, прокрутка.
- `src/components/menu/` — каталог и карточки; `src/components/navbar/` — навигация и поиск.
- `src/utils/cart.test.js` — автоматические проверки бизнес-логики.
- `.github/workflows/ci.yml` — lint, тесты и сборка на PR.

## Ограничения
Нет настоящих заказов, доставки, backend, регистрации и оплаты. Изображения каталога загружаются со стороннего сайта и могут быть недоступны. Демо нельзя использовать как официальный сервис.

## AI disclosure
При доработке использовалась помощь AI для подготовки и проверки изменений. Проект требует самостоятельного понимания и дальнейшего сопровождения разработчиком; не следует представлять автоматически предложенный код как полностью написанный вручную.
